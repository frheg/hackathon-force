FORCE VibeCode Hackathon · Stavanger · November 2026

Subsurface Studio — tools for exploration, drilling, production and late-life work on Norwegian Continental Shelf data.

Each tool takes one slow, expensive task, runs it on public NCS data (Sodir FactPages, Diskos report passages, FORCE 2020 logs, Volve drilling reports, seismic), and uses a language model only where reading, cross-checking or writing is the bottleneck. Every number is traceable to its source.
